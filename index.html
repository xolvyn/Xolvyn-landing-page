Frequently asked questions

How is Xolvyn different from local code-intelligence CLI tools?

Those tools make one developer’s AI agent smarter on their own machine. Xolvyn is built for the team: a workspace humans read, reviews posted right in your pull requests, seats, and a dashboard your eng lead can actually read. No install, no binary, no agent required.

What does the GitHub PR bot actually do?

On every pull request, Xolvyn analyzes the diff against your full dependency graph and posts a comment with a grade, the security findings, and the blast radius — what depends on what you changed, and what breaks if it ships.

Will Xolvyn merge code without my approval?

Never. Auto-fix opens a pull request for you to review — nothing merges without a human approving it.

How does Xolvyn rank vulnerabilities by blast radius?

Xolvyn builds an AST-based dependency graph, then scores each finding by how many files depend on the affected file. A medium-severity issue on a file 47 others rely on can outrank a critical issue on an isolated file — so you fix what can actually break your system first.

Does Xolvyn store or train on my code?

No. Xolvyn shallow-clones your repository, analyzes it in memory, and deletes it immediately. Access is OAuth-only, and your code is never used to train any model.

What languages does Xolvyn support?

AST-based dependency mapping covers TypeScript, JavaScript, Python, Go, and Java. Security scanning runs across your whole repository, including config and infrastructure files.

Security & Privacy

  • Zero code retention. Xolvyn performs a shallow git clone, runs analysis in memory, and immediately deletes your source. We store only computed metadata — never your actual code.
  • No AI training on your code. Your codebase is never used to train any AI model — ours or third-party.
  • OAuth-only authentication. We use GitHub and GitLab OAuth. Your tokens are encrypted at rest with AES-256 and transmitted over TLS 1.3.
  • SOC 2 Type II in progress. Targeting certification before general availability. Enterprise self-hosted option available for air-gapped environments.
  • GDPR & CCPA compliant. Right to data deletion honored within 30 days. Email hello@xolvyn.dev for requests.

Last updated: 2026 · A full security whitepaper will be published at launch.

Privacy Policy
