Common questions about Xolvyn, security, and the waitlist

Does Xolvyn store or train AI on my source code?

No, never. Xolvyn performs a shallow git clone with depth=1 into an isolated temporary directory, runs the entire analysis in memory, and immediately deletes the clone. We store only computed metadata — architecture maps, complexity scores, and security findings — never your source code itself. Your code is never used to train any AI model, ours or third-party. Your intellectual property stays yours.

How is the @mentor AI different from ChatGPT or GitHub Copilot?

Generic AI tools like ChatGPT and GitHub Copilot answer questions based on general training data — they have no awareness of what's actually in your specific codebase. Xolvyn's @mentor is grounded in your real dependency graph. It knows every file that exists, how each module imports others, what every function exports, and how layers connect. Ask "where is the auth logic?" and you get an actual file path and the routes it connects to — never a hallucination.

Which programming languages and frameworks does Xolvyn support?

Xolvyn currently supports TypeScript, JavaScript (both ESM and CommonJS), Python, Go, and Java with full AST-level dependency mapping. The security audit engine works on every text-based source file regardless of language. Monorepo tooling — including Turborepo, Nx, Lerna, and Yarn Workspaces — is supported natively. PHP, Ruby, and Rust are on the roadmap for the next quarterly release.

How does the AI Auto-Fix Engine create Pull Requests?

When a security finding is marked auto-fixable, clicking "Apply Fix" triggers the Xolvyn Auto-Fix Engine. It reads the vulnerable code snippet, generates a safe replacement using AST-aware remediation logic, commits the fix to a new branch on your repository, and opens a Pull Request automatically through the GitHub or GitLab App. For dependency CVEs, it bumps the version in your package.json, requirements.txt, or go.mod and opens the PR. Every fix includes a confidence score, and nothing merges without your explicit review and approval.
